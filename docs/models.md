# Model and dependency notes

- English dictation uses Android on-device en-IN. Regional dictation uses sherpa-onnx 2.0.2 and bundled INT8 Whisper Tiny, with a Telugu-tuned model from vasista22 for Telugu segments. Mixed mode requests a dominant language among en, te, and hi per speech segment. [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/v2.0.2) · [Telugu fine-tune](https://huggingface.co/vasista22/whisper-telugu-tiny)
- Android and the private server use in-repository deterministic rules for issue classification and common identifier patterns. The rules run without weights and no cloud inference endpoint is configured.
- sherpa-onnx supports Android under Apache-2.0. Individual speech model weights require separate license and language validation before distribution. [sherpa-onnx upstream](https://github.com/k2-fsa/sherpa-onnx)
- FieldOS bundles the Desert Ant Labs Kotlin SDK 4.3.0 for Tongue, Redact, Gist and Clear under the vendor license. Tongue weights ship with the app. The Models tab prepares and checks the three downloadable models using the vendor cache. Tongue and Gist assist text review, and Redact is applied to English drafts. Clear runs a readiness check on synthetic audio. [Android SDK](https://desertant.com/kotlin/) · [Vendor license](https://license.desertant.com/latest)
- Hindi dictation downloads a pinned 140 MB Hindi IndicConformer model once and validates the size and SHA-256 of both files. The model was originally trained by AI4Bharat on an MIT license. The ngiftsun ONNX INT8 repackaging is CC BY 4.0. When available, the Hindi model also transcribes Hindi regions detected in mixed clips. [Hindi model and credits](https://huggingface.co/ngiftsun/indicconformer-hi-int8-sherpa) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- ML Kit Translation downloads English, Telugu and Hindi models on demand and translates locally once installed. Mixed notes are segmented into Latin, Telugu and Devanagari script runs before translation. This supports native-script notes and English, with no guarantee for Romanized Telugu or Hindi. [Translation guide](https://developers.google.com/ml-kit/language/translation/android)
- The Android application uses Kotlin, AndroidX Activity Compose and Material 3. Review their Apache-2.0 notices and transitive dependency notices before redistributing outside the demo. Node is MIT-licensed and bundles SQLite, which is public-domain software.
